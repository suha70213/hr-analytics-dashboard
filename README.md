# HR Analytics Dashboard | Power BI

An interactive HR Analytics Dashboard built with Power BI to analyze workforce data and support data-driven decisions.

## 📊 Dashboard Pages

- **Overview** — Key workforce metrics
- **Attrition** — Turnover analysis by department, salary band, experience level, and gender
- **Compensation** — Salary analysis using Decomposition Tree
- **Performance** — Performance and job satisfaction analysis
- **Demographics** — Workforce composition by gender, age, and education

## 🛠️ Tools & Skills Used

- **Power Query** — Data cleaning and transformation
- **Data Modeling** — Star Schema with relationships
- **DAX** — 18 measures including Attrition Rate, High Performer Rate, Gender Ratio
- **Visualizations** — Cards, Bar Charts, Donut Charts, Matrix, Scatter Plot, Decomposition Tree, Gauge
- **Page Navigator** — Interactive navigation between pages
